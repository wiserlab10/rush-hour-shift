# 러시아워 쉬프트 (Rush Hour Shift)

ThinkFun **Rush Hour Shift** 규칙의 2인용 모바일 웹 게임. 골드/실버 히어로가 6×14 주차 그리드에서 상대 쪽 끝으로 먼저 완전히 빠져나가면 이긴다.

세 장의 주차 판(5+4+5)이 가로로 이어진다. **가운데 판은 고정**, 왼쪽/오른쪽 끝 판만 위아래로 밀 수 있다. 이음새에 차가 걸쳐 있으면 그 판은 **잠긴다**.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 [http://127.0.0.1:38471](http://127.0.0.1:38471) 을 연다.

폰에서는 공개 주소(세션마다 다를 수 있음)로 연다. 방 만들기는 **방 만들기 → 배치 선택**이면 `/r/코드`로 바로 들어간다.

```bash
npm run build
npm start
```

```bash
npm test
```

## 플레이

1. **한 폰에서** — 핫시트. 턴이 끝나면 패가 안 보이게 폰을 넘긴다.
2. **방 만들기** — 닉네임을 적고 배치를 고르면 `/r/코드` 로 바로 들어간다. **링크 복사 / 공유**로 친구 폰에 보낸다. 친구가 그 링크를 열면 이름을 정한 뒤 실버로 입장한다. 방 안 **톡**으로 짧게 주고받을 수 있다.
3. 각자 패 4장. 턴마다 카드 1장을 내고 효과를 쓴 뒤 1장을 뽑는다.
4. **이동(1–4)** 칸을 여러 차에 나눠도 된다. 상대 히어로는 못 움직인다.
5. **직진**은 한 대를 같은 줄(가로/세로)에서 막히기 전 **원하는 칸**에 세운다. 끝까지 강제 이동하지 않는다. 히어로가 반대편 끝으로 완전히 나가면 즉시 승.
6. **쉬프트**는 왼쪽 또는 오른쪽 끝 판을 **세로로** 여러 줄. 1칸 제한 없음. 잠기거나 판이 떨어지면 안 된다. 그 턴에는 차를 못 움직인다. 화면의 좌우 화살표는 가로 차를 미는 것이지 판 쉬프트가 아니다.
7. **콤보**의 숫자 N은 차 이동과 판 밀기의 **공유 포인트**(차 1칸=1, 판 1줄=1). 섞어 쓰거나 한쪽에 몰아도 된다. 순서는 그때그때 고른다.

초기 배치는 설명서 **초기 배치 방법** 카드 1–10을 칸 단위로 옮긴 것이다. 2칸 승용차와 3칸 트럭, 가로/세로가 그림과 같다.

장애물 차는 보드 밖으로 나갈 수 없다.

## 배포

온라인 방은 `SUPABASE_URL` + `SUPABASE_ANON_KEY` 가 있으면 Postgres(`rhs_rooms`)에 저장한다. 두 폰이 다른 서버리스 인스턴스를 맞아도 같은 방을 본다. 동기화는 1초 폴링이 기준이고, SSE는 같은 프로세스에서만 보너스다.

로컬에서 이 변수가 없으면 예전처럼 메모리+임시 파일을 쓴다.

```bash
npx vercel deploy --prod
```

Vercel 프로젝트에 위 두 환경 변수를 넣는다. 로그인 없이 임시 URL을 만들 때는 `npx vercel deploy --temporary --yes` 뒤에 `-e SUPABASE_URL=... -e SUPABASE_ANON_KEY=...` 를 붙인다.

## 스택

Next.js, TypeScript, Tailwind CSS. 규칙은 `src/lib/game`에서 검증하고, 온라인 방은 `/api/rooms` + SSE로 동기화한다.
